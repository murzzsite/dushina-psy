Лендинг. Светлая тема «рассвет над Уралом». Чистый HTML/CSS/JS, без сборки.

- `index.html`, `styles.css`, `script.js` — лендинг
- `privacy.html` — политика конфиденциальности
- `assets/beloretskview.jpg` — фото Белорецка (CC BY-SA 3.0, IlshatS, Wikimedia Commons), кредит в подвале

## Идея и анимации
- Дыхательный круг в hero дышит по ритму из первого «чуда»: вдох 4, выдох 6.
- Мысли → ответы: 13 страхов и возражений ЦА, ответ меняется по клику.
- Тропа «Как мы будем идти» дорисовывается по скроллу, точки загораются.
- Семь чудес: липкая сцена слева меняет символ и название по мере скролла.
- Хребты Урала с параллаксом, слова заголовков поднимаются по одному, счётчики цен, плавный FAQ.
- `prefers-reduced-motion`: всё видно сразу, без движения.
